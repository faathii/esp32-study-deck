# 💻 Firmware — ESP32 Study Deck

Esta carpeta contiene el código fuente del firmware para la estación de estudio inteligente.

---

## 📂 Proyectos Disponibles

1. **[`study_deck/`](study_deck/)**:
   - Firmware de producción de la estación de estudio.
   - Incluye el motor Pomodoro, reloj, interfaz visual táctil completa, integración con LED RGB, sensor LDR y alertas de audio.

2. **[`test_hardware/`](test_hardware/)**:
   - Sketch de diagnóstico y verificación de componentes.
   - Ideal para comprobar si tu pantalla es resistiva o capacitiva, probar el sensor LDR, el zumbador y el LED RGB antes de flashear el firmware principal.
